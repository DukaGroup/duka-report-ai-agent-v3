# Duka Group brand assets

Unmodified logos and icons from the official Duka Group website. Stored locally so app branding works without an external request at runtime.

Official palette from the website’s Elementor global styles: navy `#082340`, blue `#5792CC`.

`hana-portrait.webp` is Hana's portrait, converted unchanged from the image the user supplied (`ai_assistant.png`; the original is kept as `assets/hana-portrait-source.png`). `hana-portrait-192.png` is its face crop for notifications. The intro, farewell and profile animate her mouth and eyelids over this photo; the chat shows her as an animated orb instead of a picture.
